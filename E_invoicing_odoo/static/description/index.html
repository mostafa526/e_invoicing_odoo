E-Invoicing Integration for Odoo 16

This module allows full integration between Odoo 16 and the Egyptian Tax Authority (ETA) E-Invoicing system. It automates the submission, validation, and tracking of invoices directly from your Odoo environment to the ETA portal.

Key Benefits: Streamlined compliance with Egypt’s e-invoicing regulations, reduced manual work, and improved audit readiness.

Key Features

  • Automatic submission of invoices to the ETA portal.
  • Secure token-based authentication and digital signature support.
  • Real-time status updates and rejection handling.
  • Automatic QR code generation for compliant e-invoices.
  • Comprehensive logging and error reporting.
  • Multi-company and multi-currency support.

Requirements

  • Odoo 16 (Community or Enterprise)
  • Activated modules: account and mail
  • Valid ETA credentials and test/production API keys

How It Works

After installing the module, configure your ETA credentials in Settings → Egyptian E-Invoicing. Once set up, every validated invoice will be automatically transmitted to the ETA API.
